  • Voice calls (1-to-1)
  • …and 60+ more

Install

🖥️ Desktop — userscript (easiest)

  1. Install Tampermonkey or Violentmonkey.
  2. Open the MiniFeather userscript — it auto-updates afterwards.
  3. Play at miniblox.io.

🤖 Android (APK)

  • From the rolling builds release.

🍎 iOS (Safari)

  • Install the free Userscripts app, allow it on miniblox.io, add the same userscript URL.

🪟 Windows / 🐧 Linux

  • MSI (Tauri) and AppImage/deb packages live on the same release.
