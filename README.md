## 📖 Overview

MiniFeather Client is a community-developed browser extension created to improve the Miniblox.io experience through interface customization, visual enhancements, HUD modules, chat utilities, camera features, cosmetics, and quality-of-life improvements.

The project is designed to remain lightweight, configurable, and easy to use while receiving regular compatibility updates, fixes, and new modules.

---

## ✨ Features

- Clean and customizable MiniFeather control panel
- Dashboard with active module, FPS, and ping information
- Custom skins, capes, logos, textures, and spritesheets
- FPS, CPS, ping, and keystrokes HUD modules
- Configurable module keybinds
- Right-click module settings
- Zoom module with up to `20×` zoom
- Titan & Tiny player scaling
- Camera Overhaul with multiple motion profiles and custom tuning
- Chat videos, clickable links, GIFs, and meme commands
- Built-in meme ID library with previews
- English, Spanish, Japanese, and Italian translations
- Custom Miniblox.io interface branding
- Optional ad visibility
- Automatically saved settings
- Lightweight, performance-focused module lifecycle
- Frequent fixes, improvements, and feature updates

## 🎮 Module Controls

Most configurable MiniFeather modules use the same controls:

- **Left-click** → Enable or disable the module
- **Right-click** → Open the module settings
- **Keybind** → Toggle or use supported modules while playing

Settings and keybinds are saved automatically.

---

## 🔍 Zoom

The Zoom module provides a closer view while playing.

- Default bind: `Z`
- Hold the bind and use the mouse wheel to zoom
- Zoom range: `1×` to `20×`
- `Ctrl + Scroll` provides finer zoom adjustments
- Releasing the bind instantly returns the camera to normal
- Right-click the module to change or remove the bind

---

## 🧍 Titan & Tiny

Titan & Tiny changes the local player scale.

- Scale range: `0.20×` to `5.00×`
- Tiny preset: `0.35×`
- Normal preset: `1.00×`
- Titan preset: `3.00×`
- Custom scale values
- No keybind is assigned by default
- Right-click the module to configure scale and keybind
- Local hitbox, camera height, and native nametag synchronization are handled automatically while the module is active

Camera behavior at unusual scales may continue receiving improvements.

---

## 🎥 Camera Overhaul

Camera Overhaul adds smoother and more expressive camera movement while preserving configurable limits.

Available profiles:

- **Soft** → Subtle camera motion
- **Normal** → Balanced enhanced movement
- **Strong** → More noticeable and responsive motion
- **Custom** → Automatically selected when any camera value differs from the built-in presets

Custom settings include:

- Overall strength
- Strafe roll
- Turn roll
- Movement pitch
- Vertical pitch
- Head bob strength
- Bob frequency
- Landing impact
- Idle sway
- Speed-based FOV
- Mouse response

Camera Overhaul has no keybind assigned by default. Right-click the module to configure the profile, custom values, and keybind.

## 📥 Installation

1. Open the repository's **Releases** section.
2. Download the latest MiniFeather Client `.zip` file.
3. Extract the downloaded archive.
4. Open the extensions page in your Chromium-based browser:

   ```text
   chrome://extensions
   ```

5. Enable **Developer mode**.
6. Click **Load unpacked**.
7. Select the extracted MiniFeather Client folder.
8. Open or reload **Miniblox.io**.

---

## 🔄 Updating

1. Download the newest release.
2. Extract the new archive.
3. Replace the previous MiniFeather Client folder.
4. Open:

   ```text
   chrome://extensions
   ```

5. Reload the MiniFeather Client extension.
6. Reload Miniblox.io.
