## 📖 Overview

MiniFeather Client is a community-developed browser extension created to improve the Miniblox.io experience through interface customization, visual enhancements, useful HUD modules, and quality-of-life features.

The project is designed to remain lightweight, configurable, and easy to use while receiving regular improvements and compatibility updates.

---

## ✨ Features

- Clean and customizable MiniFeather control panel
- Custom skins, capes, logos, and textures
- FPS, CPS, ping, and keystrokes displays
- Additional chat features
- Multiple language support
- Custom Miniblox.io interface branding
- Automatically saved settings
- Lightweight and performance-focused design
- Frequent fixes, improvements, and feature updates
