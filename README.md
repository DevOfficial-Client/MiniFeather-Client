## About

**MiniFeather Client** is a lightweight client project built for **Miniblox.io**, focused on customization, useful PvP utilities, performance improvements, and a clean user experience.

The goal is to keep the client fast and simple while giving players more control over their Miniblox experience.

## Features

### HUD

* FPS counter
* CPS counter
* Custom crosshair
* Draggable HUD elements
* Customizable player information
* Configurable HUD positions
* Clean, minimal interface

### PvP

* PvP-focused HUD
* CPS tracking
* FPS tracking
* Custom crosshair
* Combat-oriented UI
* Lightweight implementation designed to avoid unnecessary performance impact

### Customization

* Custom HUD positioning
* Configurable client settings
* Custom UI elements
* Color customization
* Persistent settings
* Client branding

### Performance

MiniFeather is designed to stay lightweight.

* Minimal background processing
* No unnecessary animations
* Efficient HUD updates
* Client-side features where possible
* Designed with lower-end systems in mind

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/DevOfficial-Client/MiniFeather-Client.git
```

### 2. Open the project

Open the cloned folder in your preferred code editor.

**VS Code** is recommended for development.

### 3. Run the client

Follow the project-specific setup instructions and launch the client.

## Configuration

MiniFeather stores client settings so your customization can persist between sessions.

Depending on the version, configurable options may include:

```text
HUD
├── FPS
├── CPS
├── Crosshair
└── Player Info

Appearance
├── Accent Color
├── UI Scale
└── HUD Position

Gameplay
└── PvP Settings
```
