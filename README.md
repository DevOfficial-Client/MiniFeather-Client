# 🪶 MiniFeather Client

### A lightweight, customizable browser client designed to enhance your experience on Miniblox.io.

---

## 📖 Overview

MiniFeather Client is a community-developed browser extension created to improve the Miniblox.io experience through interface customization, visual enhancements, useful HUD modules, gameplay utilities, and quality-of-life features.

The project is designed to remain lightweight, configurable, and easy to use while receiving regular improvements, new modules, and compatibility updates.

---

## ✨ Features

- Clean and customizable MiniFeather control panel
- Custom skins, capes, logos, textures, and visual assets
- FPS, CPS, ping, and keystrokes displays
- Additional chat features and media support
- Multiple language support
- Custom Miniblox.io interface branding
- Automatically saved settings
- Configurable module keybinds
- Right-click module configuration
- Lightweight and performance-focused design
- Frequent fixes, improvements, and feature updates

### 🔍 Zoom

MiniFeather now includes a functional **Zoom module**.

- Hold the configured keybind and use the scroll wheel to zoom
- Default keybind: `Z`
- Zoom range: `1×` to `20×`
- `Ctrl + Scroll` allows finer zoom adjustments
- Releasing the keybind immediately returns the camera to normal
- Right-click the Zoom module to change or remove its keybind
- Zoom settings are automatically saved

### 🧍 Titan & Tiny

The **Titan & Tiny** module allows you to modify the visual size of your player.

- Scale range from `0.20×` to `5.00×`
- Tiny preset: `0.35×`
- Normal preset: `1.00×`
- Titan preset: `3.00×`
- Custom scale values
- Left-click the module to enable or disable it
- Right-click the module to configure the scale and keybind
- Optional keybind with no default key assigned
- Scale and keybind settings are automatically saved
- Local hitbox, camera height, and native nametag synchronization are handled automatically

> Titan & Tiny is still receiving improvements, especially regarding camera behavior at unusual player scales.
